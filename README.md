# ☁️ そらもよう

OpenWeatherMap（無料プラン）と連携した天気予報 Web アプリです。Next.js で作っています。

## できること

- 都市名検索（日本語・英語どちらでも OK）／📍ボタンで現在地の天気
- 気温・体感温度・天気・湿度・降水確率・風速の表示
- 📅 カレンダーで日付を選ぶと、その日の予報（最高/最低・3時間ごとの予報）に切り替わる
- 週間予報の一覧（今日〜6日後）
- 🌧️ 雨の予報：「あと約30分で雨が降りそう」「16時から雨が降りそう」など時刻つきで表示、傘が必要かの判定、1時間ごとの降水確率グラフ
- 👗 服装・持ち物の提案：気温・気温差・風速・降水確率・紫外線から自動で提案
- 🔔 アラート：猛暑・寒さ・雨・気温差・強風・紫外線・雨雲接近。条件は ⚙️ 設定で変えられ、ブラウザ通知も出せる（アプリを開いている間）
- 🌿 からだと空気：紫外線（UV指数）・熱中症（暑さ指数の推定）・PM2.5・花粉
- ⭐ お気に入り：複数の都市を登録して、ワンタップで切り替え。表示名（「勤務先」など）も変えられる

## API キーの管理

API キーは **環境変数 `OPENWEATHER_API_KEY` からだけ** 読み込みます。コードには書いていません。

- ブラウザは自分のサーバーの `/api/weather` を呼ぶだけで、OpenWeatherMap へのアクセスとキーの利用はサーバー側（`src/lib/openweather.ts`）で行います。そのためキーはブラウザに送られません。
- `.env.local` は `.gitignore` に含まれているので GitHub には上がりません。

## ローカルで動かす

1. [OpenWeatherMap](https://home.openweathermap.org/api_keys) で無料の API キーを発行（有効になるまで最大2時間ほどかかることがあります）
2. `.env.example` をコピーして `.env.local` を作り、キーを入れる

   ```
   OPENWEATHER_API_KEY=あなたのキー
   ```

3. 起動

   ```bash
   npm install
   npm run dev
   ```

   http://localhost:3000 を開く

## Vercel へのデプロイ

Vercel のプロジェクト設定 → Environment Variables に `OPENWEATHER_API_KEY` を登録してからデプロイします。

## 使っている API（すべて無料プラン）

| API | 用途 |
| --- | --- |
| Geocoding API | 都市名 ⇄ 緯度経度 |
| Current Weather Data | 現在の天気 |
| Air Pollution API | PM2.5 |

OpenWeatherMap の無料プランに無いデータは [Open-Meteo](https://open-meteo.com/)（無料・APIキー不要）から取っています。

| Open-Meteo | 用途 |
| --- | --- |
| Forecast API | 7日間・1時間ごとの予報、15分ごとの降水量、UV指数、日射量（暑さ指数の推定に使用） |
| Air Quality API | 花粉（データがあるのは主にヨーロッパ） |

### 推定値について

- **暑さ指数（WBGT）**：気温・湿度・日射量・風速から推定式（小野ら 2014）で計算し、環境省の区分で表示
- **日本の花粉**：日本の花粉を出している無料 API が無いため、主な花粉の飛散時期（スギ・ヒノキ・イネ科・ブタクサ/ヨモギ）と、その日の天気（晴れ・風・雨・雨の翌日）から出した目安
